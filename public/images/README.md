# Папка для фотографий и медиафайлов свадьбы

Разместите здесь фотографии пары, площадки или фоновые изображения.

Пример:
1. Скопируйте файлы сюда, например:
   - `public/images/hero.jpg`
   - `public/images/venue.jpg`
   - `public/images/gallery-1.jpg`
2. Укажите путь в `src/config/weddingConfig.ts`:
   ```ts
   heroPhoto: {
     src: '/images/hero.jpg',
     alt: 'Фотография пары',
   }
   ```
3. Для хорошей скорости загрузки на мобильных устройствах рекомендуется сжимать фото (ширина 1600–2000px для Hero, 1200px для карточек, формат `.webp` или `.jpg`).
